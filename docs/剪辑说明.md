# 本地剪辑与版本

完整片使用 30 帧/秒，共 1373 帧，成片画幅为 1344 × 672。镜头索引采用原片时间和从零开始的帧号。原始截图保留原片字幕和边框以便对照；替换成品和净截图用于剪辑。

## 复现完整片

准备 Python 3、FFmpeg（含 libx264 和 AAC 编码器），把自备的原片放在仓库根目录下的 `视频素材/完整素材.mp4`。可用同目录说明中的视频清单核对文件大小与 SHA-256。只浏览图片无需这些依赖。

在仓库根目录依次运行：

```sh
python -m pip install -r edit/requirements.txt
python edit/render.py
python edit/fight.py
```

第一步剪辑读取原片、换角图和净截图，参考原片的切点与运动方向编排画面，合成 126 BPM 配乐并混入原片人声和音效。第二步在此基础上重做 20 个打斗镜头的 287 帧，沿用第一版音轨。12.7–14.7 秒的蓝拳与格挡从七个镜头收为五个，25 秒附近的挥臂和 38 秒附近的膝击也有调整。人物采用关键图局部变形，大角度切换仍呈动态漫画效果。

两个文件默认写入 `视频素材/完整素材_本地剪辑/`，分别以「动态配乐版」和「打斗优化版」命名。重新运行会覆盖该版本的同名输出，临时文件保存在 `.build/`。这两个脚本均在本地运行。

## 九秒试验

九秒「平台输出校准版」保留了部分原角色，用于对照；「人物替换_完整9秒_原声」是经过本地修剪补齐的版本。素材目录中的两份历史脚本对应这两步，依赖本地平台原始视频，且会更新试验目录，建议在副本中使用。公开版保留了最小状态说明和创作提示词，账号回执、下载地址和账户余额留在原工作目录。

## 视频与音频

原片、参考分段、平台输出、无声中间片和最终成片均由 Git 忽略。需要补回的视频列在[本地视频清单](本地视频清单.csv)，其中平台自动分配的文件名已作泛化；SHA-256 用于识别具体文件。仓库中的 WAV 是独立配乐，最终混音还包含自备原片的声音。
